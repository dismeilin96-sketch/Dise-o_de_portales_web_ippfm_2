# **Proyecto Catalogo** 
Este proyecto se trata de realizar una pagina web Con el nombre catalogo donde se muestren tres productos en forma de tarjetas.

## **descripcion de la tarjeta**
La estructura de esta tarjeta, es la siguiente:

En la parte superior se encuentra el nombre del producto, utilizando un color más claro que el fondo. Debajo, se muestra la imagen del producto Más abajo, encontramos una pequeña descripción del mismo. Por último, se incluye un botón para ver más información sobre el producto,
En cuanto a los colores, se utiliza una combinación de marrón apagado y amarillo muy claro, con una tonalidad pastel.
